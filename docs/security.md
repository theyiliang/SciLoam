# 安全与隐私

## 身份与会话

- 单密码登录，密码使用 PBKDF2-SHA256 存储，不保存明文。
- 会话令牌只以哈希形式落库；修改密码后旧会话立即失效。
- 写请求校验 CSRF；Cookie 在生产环境启用 `Secure`。
- 连续失败登录与敏感操作受服务端限流。

## 权限模型

- 项目角色（负责人/成员）与知识库空间角色（负责人/编辑/只读）相互独立。
- 加入项目不会自动获得个人库或协作库的访问权。
- 固定类型的项目依据库与成果库按产品规则授权。
- 每次请求在服务端重新判定权限，权限变更即时生效；前端提示不构成授权。

## 审核边界

- 送审生成只读快照，审核只读取该快照。
- 审核通过仅将快照副本发布到成果空间，不回写来源空间。
- 审核人无法借审核访问来源知识库的其他版本或文件。

## 数据边界

- 默认本地检索，不向外部发送材料。
- 配置外部模型或向量服务后，仅发送当前请求方有权访问的片段。
- 生产环境建议关闭调试输出，限制日志中的内容字段。

## 审计

- 登录、权限变更、送审、审核、删除与撤回等关键操作留存记录。
- 审计记录不向普通成员开放；后端接口独立鉴权。
