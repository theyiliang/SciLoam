# 架构说明

## 分层

```text
app/presentation      HTTP 路由、DTO、CSRF 与幂等适配、CLI、SSE
app/application       用例编排、Agent 调用、证据装配、任务与审核流程
app/domain            实体、状态机、权限规则、仓储/工作单元/AI 端口
app/infrastructure    SQLite、密码与令牌、模型网关、检索与重排
```

依赖方向自上而下：表现层依赖应用层，应用层依赖领域层；基础设施实现领域端口，由组合根注入。

## 关键模块

| 模块 | 职责 |
| --- | --- |
| `application/usecases` | 登录、空间、文档版本、送审、审核、目标与成员等用例 |
| `application/research` | 基于知识库的问答编排：权限过滤、检索、证据、回答 |
| `application/agents` | 问答策略与工具调用；兼容旧版适配器 |
| `domain/policies.py` | 角色、空间类型与访问判定 |
| `domain/review_snapshot.py` | 送审快照与审核可见范围 |
| `domain/goal*` | 目标树、草案、生成记录与状态流转 |
| `infrastructure/persistence` | SQLite 仓储与工作单元 |
| `infrastructure/retrieval` | 本地 BM25、可选向量索引、重排与降级 |
| `infrastructure/ai` | 模型网关与 Agent 运行时 |

## 一次问答的数据流

```text
1. 前端发起 /chat/runs，携带空间与可选版本
2. 表现层校验会话、CSRF 与幂等键
3. 应用层按实时权限确定可读取的空间与版本
4. 检索：本地 BM25，或在显式允许时使用混合检索与重排
5. 证据装配：按版本与片段截取，超预算时裁剪
6. 模型生成（可选）：仅传入授权片段
7. 输出回答、引用、缺失证据与处理事件，并持久化会话
8. 运行事件通过 SSE 推送；断线重连按运行标识恢复
```

## 版本与审核

- 文档的每次修改产生新版本，旧版本保留。
- 送审针对具体版本生成只读快照，审核人只能看到快照内容。
- 审核通过后，将快照副本写入成果空间；来源空间不被修改。
- 所有状态变化记录操作者与时间，便于复核。

## 幂等与并发

- 写接口支持请求幂等键，重试不会产生重复资源。
- 状态变更携带期望版本号，冲突返回 409 并要求刷新。
- 运行中的问答可取消；取消与断线不会污染已保存的历史。
